Provider package for Modal sandboxes. Create requires a registry image, a token pair, and an existing Modal app. Native SDK: Modal v0.11.1.

## Create

Set `MODAL_TOKEN_ID`, `MODAL_TOKEN_SECRET`, and `MODAL_APP_NAME`. Default environment: `main`.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
import { modal } from "@sandbox-kit/modal";
import { Client } from "@sandbox-kit/sandbox";

await using client = new Client({
  provider: modal(),
  auth: {
    tokenPair: {
      id: process.env.MODAL_TOKEN_ID!,
      secret: process.env.MODAL_TOKEN_SECRET!,
    },
  },
  scope: {
    appName: process.env.MODAL_APP_NAME!,
    environment: process.env.MODAL_ENVIRONMENT ?? "main",
  },
  timeout: 120_000,
});

const sandbox = await client.create({
  source: { image: { reference: "alpine:3.21" } },
  resources: { cpuCores: 0.5, memoryMib: 512n },
  lifetime: { maximumLifetime: 5 * 60_000 },
});

console.log(sandbox.id);
```

`timeout` and `maximumLifetime` are milliseconds. `memoryMib` is a bigint.

  </Tab>
  <Tab value="Go">

```go
package main

import (
	"context"
	"fmt"
	"os"
	"time"

	"github.com/sandbox-kit/kit/sdks/go/providers/modal"
	"github.com/sandbox-kit/kit/sdks/go/sandbox"
)

func main() {
	client, err := sandbox.NewClient(modal.New(), &sandbox.Config{
		Auth: &sandbox.AuthConfig{Credentials: &sandbox.TokenPair{
			TokenPair: &sandbox.TokenPairCredentials{
				Id:     os.Getenv("MODAL_TOKEN_ID"),
				Secret: os.Getenv("MODAL_TOKEN_SECRET"),
			},
		}},
		Scope: &sandbox.Scope{
			AppName:     sandbox.Value(os.Getenv("MODAL_APP_NAME")),
			Environment: sandbox.Value("main"),
		},
		Timeout: sandbox.Duration(2 * time.Minute),
	})
	if err != nil {
		panic(err)
	}
	defer client.Close(context.Background())

	instance, err := client.Create(context.Background(), &sandbox.CreateOptions{
		Source: &sandbox.SandboxSource{Kind: &sandbox.Image{
			Image: &sandbox.ImageSource{Reference: "alpine:3.21"},
		}},
		Resources: &sandbox.Resources{
			CpuCores:  sandbox.Value(0.5),
			MemoryMib: sandbox.Value(uint64(512)),
		},
		Lifetime: &sandbox.LifetimePolicy{
			MaximumLifetime: sandbox.Duration(5 * time.Minute),
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Println(instance.ID())
}
```

  </Tab>
</Tabs>

Omit `auth` to use Modal SDK / profile credentials. `scope.appName` remains required. `endpoint` is rejected. Closing the client does not terminate the sandbox.

## Configuration

| Setting       | Notes                                              |
| ------------- | -------------------------------------------------- |
| Token pair    | `auth.tokenPair` / `TokenPair`                     |
| OAuth refresh | Supported with client id and one secret or JWT key |
| App           | `scope.appName` — required                         |
| Environment   | `scope.environment` (often `main`)                 |
| Region        | `region` — default placement preference            |
| Endpoint      | Unsupported                                        |

Full rules: [Configuration](/docs/configuration).

## Operations

| Area      | Support                                                                                   |
| --------- | ----------------------------------------------------------------------------------------- |
| Create    | Registry image; runtime, isolation, resources, network, ports, secrets, readiness, labels |
| Open      | `attach` (id only). `get` / `refresh` unsupported                                         |
| Lifecycle | `terminate`, `close`. Start/stop/pause/archive/delete unsupported                         |
| Files     | Full filesystem API — [Filesystem](/docs/filesystem)                                      |
| Process   | `run` — [Run a command](/docs/process)                                                    |

When set, resources require ≥ 0.125 CPU and ≥ 128 MiB. Disk cannot be raised at create.
