Each example is a small project under `examples/<language>/<provider>/<area>/`. It loads its own `.env` and demonstrates one call.

| Area                                 | Runtime                       |
| ------------------------------------ | ----------------------------- |
| `configuration`                      | Provisions a real sandbox     |
| `filesystem`, `process`, `lifecycle` | Uses `*_SANDBOX_ID` in `.env` |
| `errors`                             | Fails locally; no cloud work  |

Destructive ops (stop, terminate, archive, delete, remove) can destroy the sandbox or path you configure. Full catalog: [examples/README.md](https://github.com/sandbox-kit/kit/blob/main/examples/README.md).

## Run

Requirements: Node.js 20/22/24.15+ (npm 11.19.0) or Go 1.26.0+. `<area>` is `filesystem`, `process`, `configuration`, `lifecycle`, or `errors`. Skip `cp` if `.env` exists.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```sh
git clone https://github.com/sandbox-kit/kit.git
cd kit/examples/typescript/<provider>/<area>/<project>
cp .env.example .env
npm install && npm run build && npm start
```

  </Tab>
  <Tab value="Go">

```sh
git clone https://github.com/sandbox-kit/kit.git
cd kit/examples/go/<provider>/<area>/<project>
cp .env.example .env
go run .
```

  </Tab>
</Tabs>

Daytona create needs `DAYTONA_API_KEY`. Modal create needs `MODAL_TOKEN_ID`, `MODAL_TOKEN_SECRET`, and `MODAL_APP_NAME`.
