---
title: Examples
description: Clone an example project, set .env, and run one operation.
---

Each example is a small project that loads its own `.env` and demonstrates one call against a provider. Creation examples provision a real sandbox. Filesystem, process, and lifecycle examples need a sandbox id in `.env`. Error examples fail locally.

Destructive ops (stop, terminate, archive, delete, remove) can destroy the sandbox or path you configure.

## Run

Skip `cp` if `.env` already exists.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

Requires Node.js 20/22/24.15+ and npm 11.19.0.

<ForProvider id="daytona">

```sh
git clone https://github.com/sandbox-kit/kit.git
cd kit/examples/typescript/daytona/configuration/create-daytona-sandbox
cp .env.example .env   # set DAYTONA_API_KEY
npm install && npm run build && npm start
```

</ForProvider>
