Each project selects one provider, loads a `.env` file, and performs one operation. Open the project for the call you need.

Creation projects provision a real sandbox. Lifecycle projects use the sandbox id in `.env`. Stop, terminate, archive, and delete can destroy that sandbox. Error projects fail locally and create nothing.

The tables below are the common projects. The repository also has network, labels, secrets, pause, and archive. The full list is the [examples catalog](https://github.com/sandbox-kit/kit/blob/main/examples/README.md).

## Run a project

TypeScript needs Node.js 20, 22, or 24.15+. Go needs Go 1.26.0 or later. Replace the path with the project you opened above. Skip `cp .env.example` when you already have a `.env`.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```sh
git clone https://github.com/sandbox-kit/kit.git
cd kit/examples/typescript/<provider>/<project>
cp .env.example .env
npm install && npm run build && npm start
```

  </Tab>
  <Tab value="Go">

```sh
git clone https://github.com/sandbox-kit/kit.git
cd kit/examples/go/<provider>/<project>
cp .env.example .env
go run .
```

  </Tab>
</Tabs>

Put the variables from that project's `.env.example` into `.env`. Daytona create uses `DAYTONA_API_KEY`. Modal create uses `MODAL_TOKEN_ID`, `MODAL_TOKEN_SECRET`, and `MODAL_APP_NAME`.
