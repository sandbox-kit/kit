---
title: Run a command
description: Blocking Process.run — argv or shell, cwd, env, timeouts, and exit codes.
---

Use `sandbox.process.run` (TypeScript) or `Process().Run` (Go) on an open handle. Providers share the same options and result shape; switch Daytona or Modal above for mapping and edge cases.

| Method        | Returns                                                                |
| ------------- | ---------------------------------------------------------------------- |
| `run` / `Run` | `exitCode` / `exit_code`, `stdout`, `stderr` when the command finishes |

Prerequisite: create or open a sandbox ([Daytona](/docs/daytona), [Modal](/docs/modal), or [Lifecycle](/docs/lifecycle)).

## Options

Set **exactly one** of:

| Field   | Meaning                  | Example             |
| ------- | ------------------------ | ------------------- |
| `argv`  | Program + arguments      | `["echo", "hello"]` |
| `shell` | One shell command string | `"echo hello"`      |

| Field              | Rules                                                                                      |
| ------------------ | ------------------------------------------------------------------------------------------ |
| Both or neither    | Rejected before the provider call. Field: `argv`                                           |
| Blank `shell`      | Rejected. Field: `shell`                                                                   |
| `workingDirectory` | Absolute path when set (`/workspace`). Relative, blank, or NUL → field `working_directory` |
| `environment`      | Map for this call only. Omitted → provider default. Empty map is explicit                  |
| `timeout`          | TypeScript: ms. Go: `time.Duration`. Omit → client deadline. `0` → no extra Kit deadline   |

### Provider mapping

<ForProvider id="daytona">

| Kit input                      | Daytona                                                   |
| ------------------------------ | --------------------------------------------------------- |
| `argv`                         | POSIX-quoted shell string                                 |
| `shell`                        | shell as-is                                               |
| omitted / zero timeout         | command timeout `0` (avoids Daytona's 10s native default) |
| fractional seconds (`1500` ms) | rejected (`timeout`)                                      |

</ForProvider>

<ForProvider id="modal">

| Kit input                      | Modal                                                          |
| ------------------------------ | -------------------------------------------------------------- |
| `argv`                         | argv as-is                                                     |
| `shell`                        | `bash -c`                                                      |
| omitted / zero timeout         | no command limit — TS omits `timeoutMs` (never `0`); Go `Timeout: 0` |
| fractional seconds (`1500` ms) | rejected (`timeout`)                                                 |

</ForProvider>

### Result

| Field                    | Notes                            |
| ------------------------ | -------------------------------- |
| `exitCode` / `exit_code` | Non-zero is **not** an SDK error |
| `stdout`                 | Bytes                            |
| `stderr`                 | See provider note below          |

<ForProvider id="daytona">
  Daytona basic exec leaves `stderr` empty (Go: non-nil empty slice); stdout may include merged streams.
</ForProvider>

<ForProvider id="modal">Modal collects both `stdout` and `stderr`.</ForProvider>

Calls on one handle are serialized with lifecycle and filesystem. A second handle for the same sandbox does not wait.

## argv

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const result = await sandbox.process.run({
  argv: ["echo", "hello from kit"],
  timeout: 5_000,
});
console.log(result.exitCode, new TextDecoder().decode(result.stdout));
```

  </Tab>
  <Tab value="Go">

```go
result, err := instance.Process().Run(ctx, &sandbox.ExecOptions{
	Argv:    []string{"echo", "hello from kit"},
	Timeout: sandbox.Duration(5 * time.Second),
})
if err != nil {
	return err
}
fmt.Printf("exit=%d stdout=%q\n", result.GetExitCode(), string(result.GetStdout()))
```

  </Tab>
</Tabs>

## shell

Do not set `argv` on the same call.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const result = await sandbox.process.run({
  shell: 'echo "hello from shell"',
});
```

<ForProvider id="daytona">
  Daytona runs the string as shell. Modal wraps with `bash -c` instead—same Kit
  call shape.
</ForProvider>

<ForProvider id="modal">
  Modal runs this as `bash -c`. Daytona uses the shell string as-is—same Kit
  call shape.
</ForProvider>

  </Tab>
  <Tab value="Go">

```go
result, err := instance.Process().Run(ctx, &sandbox.ExecOptions{
	Shell: sandbox.Value(`echo "hello from shell"`),
})
```

  </Tab>
</Tabs>

## Working directory and environment

Applies to that call only.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const result = await sandbox.process.run({
  argv: ["printenv", "KIT_DEMO"],
  workingDirectory: "/tmp",
  environment: { KIT_DEMO: "from-kit" },
});
```

  </Tab>
  <Tab value="Go">

```go
result, err := instance.Process().Run(ctx, &sandbox.ExecOptions{
	Argv:             []string{"printenv", "KIT_DEMO"},
	WorkingDirectory: sandbox.Value("/tmp"),
	Environment:      map[string]string{"KIT_DEMO": "from-kit"},
})
```

  </Tab>
</Tabs>

## Non-zero exit code

Transport and validation failures still return errors. A finished command with exit `7` does not.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const result = await sandbox.process.run({ shell: "exit 7" });
if (result.exitCode !== 7) {
  throw new Error(`want exit 7, got ${result.exitCode}`);
}
```

  </Tab>
  <Tab value="Go">

```go
result, err := instance.Process().Run(ctx, &sandbox.ExecOptions{
	Shell: sandbox.Value("exit 7"),
})
if err != nil {
	return err
}
if result.GetExitCode() != 7 {
	return fmt.Errorf("want exit 7, got %d", result.GetExitCode())
}
```

  </Tab>
</Tabs>
