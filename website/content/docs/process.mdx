Run a command on an open handle. You need a sandbox from [create](/docs/create) or [lifecycle](/docs/lifecycle).

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

Call `sandbox.process.run`. The result includes `exitCode`, `stdout`, and `stderr`
(providers may leave `stderr` empty—see [How providers run it](#how-providers-run-it)).

  </Tab>
  <Tab value="Go">

Call `Process().Run`. The result includes `exit_code`, `stdout`, and `stderr`
(providers may leave `stderr` empty—see [How providers run it](#how-providers-run-it)).

  </Tab>
</Tabs>

## Options

Set **exactly one** of:

| Field   | Meaning                  | Example             |
| ------- | ------------------------ | ------------------- |
| `argv`  | Program + arguments      | `["echo", "hello"]` |
| `shell` | One shell command string | `"echo hello"`      |

| Field              | Rules                                                                     |
| ------------------ | ------------------------------------------------------------------------- |
| Both or neither    | Rejected. Field: `argv`                                                   |
| Blank `shell`      | Rejected after trim. Field: `shell`                                       |
| `workingDirectory` | Absolute when set. Relative, blank, or NUL → field `working_directory`    |
| `environment`      | For this call only. Omit → provider default. Empty map → add no variables |
| `timeout`          | See [Timeouts](#timeouts-and-cancel)                                      |

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const result = await sandbox.process.run({
  argv: ["echo", "hello"], // or shell: 'echo "hello"' — not both
  workingDirectory: "/tmp", // absolute when set
  environment: { KIT_DEMO: "from-kit" },
  timeout: 5_000, // milliseconds; whole seconds required
  signal: AbortSignal.timeout(5_000),
});
// result: { exitCode, stdout, stderr }
console.log(result);
```

  </Tab>
  <Tab value="Go">

```go
result, err := instance.Process().Run(ctx, &sandbox.ExecOptions{
	Argv:             []string{"echo", "hello"}, // or Shell — not both
	WorkingDirectory: sandbox.Value("/tmp"),     // absolute when set
	Environment:      map[string]string{"KIT_DEMO": "from-kit"},
	Timeout:          sandbox.Duration(5 * time.Second), // whole seconds
})
if err != nil {
	return err
}
// result: ExitCode, Stdout, Stderr
fmt.Println(result)
```

  </Tab>
</Tabs>

### How providers run it

<ForProvider id="daytona">

| You pass               | On Daytona                                                      |
| ---------------------- | --------------------------------------------------------------- |
| `argv`                 | POSIX-quoted shell string                                       |
| `shell`                | shell string as-is                                              |
| omit / zero timeout    | no command limit (`0`, so Daytona does not use its 10s default) |
| fractional (`1500` ms) | rejected (`timeout`)                                            |

Daytona returns stdout only; `stderr` is empty. stdout may include merged streams.

## Timeouts and cancel

| Setting        | Meaning                                                           |
| -------------- | ----------------------------------------------------------------- |
| Omit `timeout` | Use the client default deadline                                   |
| `0`            | No extra client deadline for this call                            |
| Positive value | Cap this call; must be whole seconds (`5000` ok, `1500` rejected) |

Omit or zero also means no separate provider command limit.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

Abort rejects the `await`; the remote command may keep running. The handle stays busy until the in-flight call finishes.

```ts
const ac = new AbortController();
const pending = sandbox.process.run({
  argv: ["sleep", "30"],
  timeout: 0, // no deadline; still abortable
  signal: ac.signal,
});
ac.abort();
await pending.catch(() => {});
```

  </Tab>
  <Tab value="Go">

Cancel the context to end the wait. The handle stays busy until the in-flight call finishes.

```go
ctx, cancel := context.WithCancel(ctx)
defer cancel()

result, err := instance.Process().Run(ctx, &sandbox.ExecOptions{
	Argv:    []string{"sleep", "30"},
	Timeout: sandbox.Duration(0), // no deadline; still cancelable via ctx
})
_ = result
_ = err
```

  </Tab>
</Tabs>

## Non-zero exit code

Transport and validation failures still return errors. A finished command with exit `7` does not.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const result = await sandbox.process.run({ shell: "exit 7" });
if (result.exitCode !== 7) {
  throw new Error(`want exit 7, got ${result.exitCode}`);
}
```

  </Tab>
  <Tab value="Go">

```go
import (
	"fmt"

	"github.com/sandbox-kit/kit/sdks/go/sandbox"
)

result, err := instance.Process().Run(ctx, &sandbox.ExecOptions{
	Shell: sandbox.Value("exit 7"),
})
if err != nil {
	return err
}
if result.GetExitCode() != 7 {
	return fmt.Errorf("want exit 7, got %d", result.GetExitCode())
}
```

  </Tab>
</Tabs>
