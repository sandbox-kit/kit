## Open a sandbox

<ForProvider id="daytona">

`get` loads a sandbox that already exists. `refresh` loads it again. `attach` is not available.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const sandbox = await client.get(process.env.DAYTONA_SANDBOX_ID!);
const info = await sandbox.refresh();
// info: { id, provider, name?, providerState?, region?, isolation?,
//         resources?, labels, createdAt?, providerMetadata?, state, terminal? }
console.log(info);
```

  </Tab>
  <Tab value="Go">

```go
import "os"

instance, err := client.Get(ctx, os.Getenv("DAYTONA_SANDBOX_ID"))
if err != nil {
	return err
}
if err := instance.Refresh(ctx); err != nil {
	return err
}
// Info(): Id, Provider, Name, ProviderState, Region, Isolation,
//         Resources, Labels, CreatedAt, ProviderMetadata, State, Terminal
fmt.Println(instance.Info())
```

  </Tab>
</Tabs>

</ForProvider>

## Stop, start, pause, and archive

`stop` leaves the sandbox available to start again. `start` brings a stopped or archived sandbox back. `pause` keeps memory. `archive` moves a retained sandbox into archive storage.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
import { LifecycleCapability } from "@sandbox-kit/sandbox";

const sandbox = await client.get(process.env.DAYTONA_SANDBOX_ID!);

if (!sandbox.supports(LifecycleCapability.Stop)) {
  throw new Error(`sandbox ${sandbox.id} cannot be stopped`);
}

const info = await sandbox.stop({ timeout: 60_000 });
// info: { id, provider, name?, providerState?, region?, isolation?,
//         resources?, labels, createdAt?, providerMetadata?, state, terminal? }
console.log(info);
```

`timeout` is milliseconds. Pass `force: true` for an immediate stop. Check `supports` the same way before `start`, `pause`, or `archive`.

  </Tab>
  <Tab value="Go">

```go
import (
	"fmt"
	"os"
	"time"

	"github.com/sandbox-kit/kit/sdks/go/sandbox"
)

instance, err := client.Get(ctx, os.Getenv("DAYTONA_SANDBOX_ID"))
if err != nil {
	return err
}
if !instance.Supports(sandbox.LifecycleCapabilityStop) {
	return fmt.Errorf("sandbox %s cannot be stopped", instance.ID())
}
if err := instance.Stop(ctx, &sandbox.StopOptions{
	Timeout: sandbox.Duration(time.Minute),
}); err != nil {
	return err
}
// Info(): Id, Provider, Name, ProviderState, Region, Isolation,
//         Resources, Labels, CreatedAt, ProviderMetadata, State, Terminal
fmt.Println(instance.Info())
```

`Start`, `Pause`, and `Archive` take the same kind of options.

  </Tab>
</Tabs>

Daytona decides whether that sandbox can pause, archive, or stop. An ephemeral sandbox can still end via the lifetime you set at [create](/docs/create).

</ForProvider>

## Delete

`delete` removes a Blaxel sandbox. On success, `state` is `deleted` and
`terminal` is true. Omit `wait` to return when delete is accepted. Pass
`wait: true` to wait until removal finishes before recreate.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const sandbox = await client.get(process.env.BL_SANDBOX_NAME!);
const info = await sandbox.delete({ wait: true, timeout: 60_000 });
console.log(info.state, info.terminal);
```

  </Tab>
  <Tab value="Go">

```go
import (
	"os"
	"time"

	"github.com/sandbox-kit/kit/sdks/go/sandbox"
)

instance, err := client.Get(ctx, os.Getenv("BL_SANDBOX_NAME"))
if err != nil {
	return err
}
if err := instance.Delete(ctx, &sandbox.DeleteOptions{
	Wait:    sandbox.Value(true),
	Timeout: sandbox.Duration(time.Minute),
}); err != nil {
	return err
}
info := instance.Info()
fmt.Println(info.State, info.GetTerminal())
```

  </Tab>
</Tabs>

## Terminate

`terminate` finishes a Modal sandbox. A maximum lifetime or idle timeout set at [create](/docs/create) also ends it.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
import { LifecycleCapability } from "@sandbox-kit/sandbox";

const sandbox = await client.attach(process.env.MODAL_SANDBOX_ID!);

if (!sandbox.supports(LifecycleCapability.Terminate)) {
  throw new Error(`sandbox ${sandbox.id} cannot be terminated`);
}

const exit = await sandbox.terminate({ wait: true, timeout: 60_000 });
// exit: { exitCode? }
console.log(exit);
```

`wait: true` polls until the sandbox exits or the timeout fires. The timeout is how long the client waits—Modal does not receive it as its own terminate timeout.

  </Tab>
  <Tab value="Go">

```go
import (
	"fmt"
	"os"
	"time"

	"github.com/sandbox-kit/kit/sdks/go/sandbox"
)

instance, err := client.Attach(ctx, os.Getenv("MODAL_SANDBOX_ID"))
if err != nil {
	return err
}
if !instance.Supports(sandbox.LifecycleCapabilityTerminate) {
	return fmt.Errorf("sandbox %s cannot be terminated", instance.ID())
}
exit, err := instance.Terminate(ctx, &sandbox.TerminateOptions{
	Wait:    sandbox.Value(true),
	Timeout: sandbox.Duration(time.Minute),
})
if err != nil {
	return err
}
// exit: ExitCode
fmt.Println(exit)
```

## Close the client

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
await client.close();
```

Prefer `await using` when the client lifetime matches the block. Client dispose closes the connection. Handle dispose does not stop the sandbox.

  </Tab>
  <Tab value="Go">

```go
import "context"

defer client.Close(context.Background())
```

`Sandbox.Close` does not stop or delete the sandbox. Later calls on that handle still reach the provider.

<ForProvider id="blaxel">
  Handle `close` does not delete the sandbox. It keeps running until you
  `delete` it or a lifetime policy ends it.
</ForProvider>

  </Tab>
</Tabs>

## Read the state

`info.state` is the lifecycle state on the handle. A failed call can still
mean the cloud already changed state. See [Errors](/docs/errors).

<ForProvider id="daytona">
  After a lifecycle call, call `refresh` (or `get` again) before assuming the
  sandbox is stopped or gone.
</ForProvider>

<ForProvider id="modal">
  Use the info returned by the call, or `info()` on the handle. There is no
  `refresh` or `get` on Modal.
</ForProvider>

<ForProvider id="blaxel">
  After `delete`, use `wait: true` when you need removal to finish before
  recreate. Use `refresh` or `get` for fresh metadata while the sandbox exists.
</ForProvider>
