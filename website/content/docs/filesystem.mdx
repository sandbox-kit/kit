---
title: Filesystem
description: Read, write, copy, mkdir, list, stat, and remove paths inside a sandbox.
---

Use `sandbox.filesystem` / `Filesystem()` on an open handle. Providers implement the same methods; provider-specific timeout rules are below.

| Method                                  | Purpose                  |
| --------------------------------------- | ------------------------ |
| [`readFile`](#read-a-file)              | Read file bytes          |
| [`writeFile`](#write-a-file)            | Replace or create a file |
| [`copyFromLocal`](#copy-a-file-in)      | Local → sandbox          |
| [`copyToLocal`](#copy-a-file-out)       | Sandbox → local          |
| [`makeDirectory`](#create-a-directory)  | Create a directory       |
| [`listDirectory`](#list-a-directory)    | List one directory       |
| [`stat`](#read-metadata)                | Path metadata            |
| [`remove`](#delete-a-file-or-directory) | Delete a path            |

Prerequisite: [create](/docs/create) or [open](/docs/lifecycle) a sandbox.

## Paths and bytes

| Path kind    | Rule                                                         | Error field  |
| ------------ | ------------------------------------------------------------ | ------------ |
| Sandbox      | Absolute (`/tmp/note.txt`). Relative, blank, or NUL rejected | `path`       |
| Local (copy) | May be relative (`./note.txt`). Non-blank, no NUL            | `local_path` |

`readFile` / `writeFile` transfer bytes—encode/decode text in your app. Copy methods use files on disk.

## Timeouts

| Language   | Unit            |
| ---------- | --------------- |
| TypeScript | milliseconds    |
| Go         | `time.Duration` |

Omit timeout → client deadline. Explicit `0` → no extra Kit deadline.

<ForProvider id="daytona">

| Method / language                                              | Behavior                                                                                                                                    |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| TS `readFile`, `writeFile`, `copyFromLocal`, `copyToLocal`     | Whole seconds to Daytona. `2000` OK; `1500` rejected (`timeout`). Omit/zero → `0` (no transfer limit). Abort signal still applies when omit |
| TS `makeDirectory`, `listDirectory`, `stat`, `remove`          | Abort signal. `1500` ms ends at 1.5s                                                                                                        |
| All Go file calls                                              | Context deadline. `1500 * time.Millisecond` ends at 1.5s                                                                                    |

</ForProvider>

<ForProvider id="modal">

| Method / language                                     | Behavior                                                 |
| ----------------------------------------------------- | -------------------------------------------------------- |
| TS transfer and directory ops                         | Abort signal. `1500` ms ends at 1.5s                     |
| All Go file calls                                     | Context deadline. `1500 * time.Millisecond` ends at 1.5s |

</ForProvider>

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
await sandbox.filesystem.readFile("/tmp/note.txt", { timeout: 2_000 });
await sandbox.filesystem.listDirectory("/tmp", { timeout: 1_500 });
```

<ForProvider id="daytona">
`readFile` with `1500` is rejected on Daytona TypeScript. Use a whole-second value such as `2000`.
</ForProvider>

  </Tab>
  <Tab value="Go">

```go
data, err := instance.Filesystem().ReadFile(ctx, "/tmp/note.txt", &sandbox.FileReadOptions{
	Timeout: sandbox.Duration(1500 * time.Millisecond),
})
```

  </Tab>
</Tabs>

Calls on one handle are serialized with lifecycle and process. Snippets below assume an open `sandbox` / `instance`. See [Examples](/docs/examples).

## Read a file

`readFile` returns the bytes of one file. A missing file comes back as not found. A directory path fails at the provider.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const data = await sandbox.filesystem.readFile("/tmp/note.txt");
const text = new TextDecoder().decode(data);
console.log(text);
```

  </Tab>
  <Tab value="Go">

```go
data, err := instance.Filesystem().ReadFile(ctx, "/tmp/note.txt", nil)
if err != nil {
	return err
}
fmt.Printf("%s\n", data)
```

  </Tab>
</Tabs>

## Write a file

`writeFile` replaces the file and creates missing parent directories. An existing file at that path is overwritten.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const body = new TextEncoder().encode("hello\n");
await sandbox.filesystem.writeFile("/tmp/kit-files/note.txt", body);
```

  </Tab>
  <Tab value="Go">

```go
body := []byte("hello\n")
err := instance.Filesystem().WriteFile(ctx, "/tmp/kit-files/note.txt", body, nil)
```

## Copy a file in

`copyFromLocal` reads a file on your machine and writes it in the sandbox. The local path is the first argument. The remote path is absolute. An existing remote file is replaced, and missing parent directories of that path are created. A missing local file is not found. The error field is `local_path`. A local directory is an invalid argument with the same field.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
await sandbox.filesystem.copyFromLocal("./note.txt", "/tmp/note.txt");
```

  </Tab>
  <Tab value="Go">

```go
err := instance.Filesystem().CopyFromLocal(ctx, "note.txt", "/tmp/note.txt", nil)
```

  </Tab>
</Tabs>

## Copy a file out

`copyToLocal` copies a sandbox file onto your disk. The remote path comes first. An existing local file is replaced. A missing local parent directory is created. A local directory is an invalid argument, and the field is `local_path`.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
await sandbox.filesystem.copyToLocal("/tmp/note.txt", "./note.txt");
```

  </Tab>
  <Tab value="Go">

```go
err := instance.Filesystem().CopyToLocal(ctx, "/tmp/note.txt", "note.txt", nil)
```

## Create a directory

`parents` defaults to true, so the call creates missing parents.

<ForProvider id="daytona">
Daytona returns an error when the directory already exists. Daytona rejects `parents: false` before the call (field `parents`).
</ForProvider>

<ForProvider id="modal">
Modal accepts a directory that already exists. With `parents: false`, Modal requires the parent and errors if the new directory is already there.
</ForProvider>

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
await sandbox.filesystem.makeDirectory("/tmp/kit-files");
```

<ForProvider id="modal">

```ts
await sandbox.filesystem.makeDirectory("/tmp/kit-files/nested", {
  parents: false,
});
```

</ForProvider>

  </Tab>
  <Tab value="Go">

```go
err := instance.Filesystem().MakeDirectory(ctx, "/tmp/kit-files", nil)
```

<ForProvider id="modal">

```go
err = instance.Filesystem().MakeDirectory(ctx, "/tmp/kit-files/nested", &sandbox.MakeDirectoryOptions{
	Parents: sandbox.Value(false),
})
```

</ForProvider>

  </Tab>
</Tabs>

## List a directory

`listDirectory` returns the entries in that one directory. It does not walk into subdirectories. `size` is a byte count. In TypeScript it is a `bigint`.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const entries = await sandbox.filesystem.listDirectory("/tmp/kit-files");
for (const entry of entries) console.log(entry.name, entry.size);
```

  </Tab>
  <Tab value="Go">

```go
entries, err := instance.Filesystem().ListDirectory(ctx, "/tmp/kit-files", nil)
if err != nil {
	return err
}
for _, entry := range entries {
	fmt.Println(entry.GetName(), entry.GetSize())
}
```

  </Tab>
</Tabs>

## Read metadata

`stat` returns one path. A symlink result describes the symlink. Modal can report a symlink. Daytona reports a file or a directory. `mode` is an octal string when the provider supplies one, such as `0644`. `permissions`, `owner`, and `group` are set when the provider supplies them. `modifiedAt` is set when the provider supplies a time.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const info = await sandbox.filesystem.stat("/tmp/note.txt");
console.log(info.type, info.size, info.mode);
```

  </Tab>
  <Tab value="Go">

```go
info, err := instance.Filesystem().Stat(ctx, "/tmp/note.txt", nil)
if err != nil {
	return err
}
fmt.Println(info.GetType(), info.GetSize(), info.GetMode())
```

  </Tab>
</Tabs>

## Delete a file or directory

`remove` deletes a file, or an empty directory. Set `recursive` to delete a directory and its contents. A directory that still has entries fails when you leave the flag unset. A missing path comes back as not found.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
await sandbox.filesystem.remove("/tmp/note.txt");
await sandbox.filesystem.remove("/tmp/kit-files", { recursive: true });
```

  </Tab>
  <Tab value="Go">

```go
files := instance.Filesystem()
if err := files.Remove(ctx, "/tmp/note.txt", nil); err != nil {
	return err
}
if err := files.Remove(ctx, "/tmp/kit-files", &sandbox.RemoveOptions{
	Recursive: sandbox.Value(true),
}); err != nil {
	return err
}
```

  </Tab>
</Tabs>
