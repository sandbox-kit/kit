title: Filesystem
description: Read, write, copy, mkdir, list, stat, and remove paths inside a sandbox.
---

Use the filesystem methods on an open handle.

| Method                                  | Purpose                  |
| --------------------------------------- | ------------------------ |
| [`readFile`](#read-a-file)              | Read file bytes          |
| [`writeFile`](#write-a-file)            | Replace or create a file |
| [`copyFromLocal`](#copy-a-file-in)      | Local → sandbox          |
| [`copyToLocal`](#copy-a-file-out)       | Sandbox → local          |
| [`makeDirectory`](#create-a-directory)  | Create a directory       |
| [`listDirectory`](#list-a-directory)    | List one directory       |
| [`stat`](#read-metadata)                | Path metadata            |
| [`remove`](#delete-a-file-or-directory) | Delete a path            |

You need a sandbox from [create](/docs/create) or [lifecycle](/docs/lifecycle).

## Paths and bytes

| Path kind    | Rule                                                         | Error field  |
| ------------ | ------------------------------------------------------------ | ------------ |
| Sandbox      | Absolute (`/tmp/note.txt`). Relative, blank, or NUL rejected | `path`       |
| Local (copy) | May be relative (`./note.txt`). Non-blank, no NUL            | `local_path` |

`readFile` and `writeFile` transfer bytes—encode and decode text in your app. Copy methods use files on disk.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const body = new TextEncoder().encode("hello\n");
await sandbox.filesystem.writeFile("/tmp/note.txt", body); // absolute sandbox path
await sandbox.filesystem.copyFromLocal("./note.txt", "/tmp/note.txt"); // local may be relative
```

  </Tab>
  <Tab value="Go">

```go
err := instance.Filesystem().WriteFile(ctx, "/tmp/note.txt", []byte("hello\n"), nil)
err = instance.Filesystem().CopyFromLocal(ctx, "note.txt", "/tmp/note.txt", nil) // local may be relative
```

  </Tab>
</Tabs>

## Timeouts

Omit timeout → client deadline. Explicit `0` → no deadline from the client.

<ForProvider id="daytona">

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

Timeouts are milliseconds.

| Method                                                  | Behavior                                                                                                                                    |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `readFile`, `writeFile`, `copyFromLocal`, `copyToLocal` | Whole seconds to Daytona. `2000` OK; `1500` rejected (`timeout`). Omit/zero → `0` (no transfer limit). Abort signal still applies when omit |
| `makeDirectory`, `listDirectory`, `stat`, `remove`      | Abort signal. `1500` ms ends at 1.5s                                                                                                        |

```ts
await sandbox.filesystem.readFile("/tmp/note.txt", { timeout: 2_000 });
await sandbox.filesystem.listDirectory("/tmp", { timeout: 1_500 });
```

  </Tab>
  <Tab value="Go">

Timeouts use `time.Duration` via `sandbox.Duration`. Every file call honors the context deadline. `1500 * time.Millisecond` ends at 1.5s.

```go
data, err := instance.Filesystem().ReadFile(ctx, "/tmp/note.txt", &sandbox.FileReadOptions{
	Timeout: sandbox.Duration(1500 * time.Millisecond),
})
```

  </Tab>
</Tabs>

</ForProvider>

## Read a file

Returns the bytes of one file. A missing file is not found. A directory path fails at the provider.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const data = await sandbox.filesystem.readFile("/tmp/note.txt");
const text = new TextDecoder().decode(data);
console.log(text);
```

  </Tab>
  <Tab value="Go">

```go
import "fmt"

data, err := instance.Filesystem().ReadFile(ctx, "/tmp/note.txt", nil)
if err != nil {
	return err
}
fmt.Printf("%s\n", data)
```

  </Tab>
</Tabs>

## Write a file

Replaces the file and creates missing parent directories. An existing file is overwritten.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const body = new TextEncoder().encode("hello\n");
await sandbox.filesystem.writeFile("/tmp/kit-files/note.txt", body);
```

  </Tab>
  <Tab value="Go">

```go
err := instance.Filesystem().WriteFile(ctx, "/tmp/kit-files/note.txt", []byte("hello\n"), nil)
```

  </Tab>
</Tabs>

## Copy a file in

Reads a file on your machine and writes it in the sandbox. Local path first; remote path absolute. Replaces an existing remote file and creates missing parents. A missing local file or a local directory fails with field `local_path`.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
await sandbox.filesystem.copyFromLocal("./note.txt", "/tmp/note.txt");
```

  </Tab>
  <Tab value="Go">

```go
err := instance.Filesystem().CopyFromLocal(ctx, "note.txt", "/tmp/note.txt", nil)
```

  </Tab>
</Tabs>

## Copy a file out

Copies a sandbox file onto your disk. Remote path first. Replaces an existing local file and creates a missing local parent. A local directory fails with field `local_path`.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
await sandbox.filesystem.copyToLocal("/tmp/note.txt", "./note.txt");
```

  </Tab>
  <Tab value="Go">

```go
err := instance.Filesystem().CopyToLocal(ctx, "/tmp/note.txt", "note.txt", nil)
```

  </Tab>
</Tabs>

## Create a directory

`parents` defaults to true.

<ForProvider id="daytona">
  Daytona errors if the directory already exists, and rejects `parents: false`
  before the call (field `parents`).
</ForProvider>

<ForProvider id="modal">
  Modal accepts a directory that already exists. With `parents: false`, the
  parent must exist and the new directory must not.
</ForProvider>

<ForProvider id="blaxel">
  Missing parents are created when `parents` is omitted or true. `parents:
  false` is not supported.
</ForProvider>

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
await sandbox.filesystem.makeDirectory("/tmp/kit-files");
```

<ForProvider id="modal">

```ts
await sandbox.filesystem.makeDirectory("/tmp/kit-files/nested", {
  parents: false,
});
```

</ForProvider>

  </Tab>
  <Tab value="Go">

```go
err := instance.Filesystem().MakeDirectory(ctx, "/tmp/kit-files", nil)
```

<ForProvider id="modal">

```go
import "github.com/sandbox-kit/kit/sdks/go/sandbox"

err = instance.Filesystem().MakeDirectory(ctx, "/tmp/kit-files/nested", &sandbox.MakeDirectoryOptions{
	Parents: sandbox.Value(false),
})
```

</ForProvider>

  </Tab>
</Tabs>

## List a directory

Returns entries in that one directory—no recursion. `size` is a byte count.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

`size` is a `bigint`.

  </Tab>
  <Tab value="Go">

`size` is an integer byte count on the entry.

  </Tab>
</Tabs>

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const entries = await sandbox.filesystem.listDirectory("/tmp/kit-files");
// each entry: { name, path, type, size?, mode?, permissions?,
//               owner?, group?, modifiedAt? }
console.log(entries);
```

  </Tab>
  <Tab value="Go">

```go
import "fmt"

entries, err := instance.Filesystem().ListDirectory(ctx, "/tmp/kit-files", nil)
if err != nil {
	return err
}
// each entry: Name, Path, Type, Size, Mode, Permissions, Owner, Group, ModifiedAt
fmt.Println(entries)
```

  </Tab>
</Tabs>

## Read metadata

`stat` returns one path. `mode` is an octal string when supplied (`0644`). `permissions`, `owner`, `group`, and `modifiedAt` appear when the cloud returns them.

<ForProvider id="daytona">
  A symlink path is reported as a file or a directory.
</ForProvider>

<ForProvider id="modal">
  A symlink result describes the symlink when Modal reports one.
</ForProvider>

<ForProvider id="blaxel">
  Directories return type directory. Files return type file, with size and
  permissions when available. `name` and `path` are whatever Blaxel reports.
</ForProvider>

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const info = await sandbox.filesystem.stat("/tmp/note.txt");
// info: { name, path, type, size?, mode?, permissions?,
//         owner?, group?, modifiedAt? }
console.log(info);
```

  </Tab>
  <Tab value="Go">

```go
import "fmt"

info, err := instance.Filesystem().Stat(ctx, "/tmp/note.txt", nil)
if err != nil {
	return err
}
// info: Name, Path, Type, Size, Mode, Permissions, Owner, Group, ModifiedAt
fmt.Println(info)
```

  </Tab>
</Tabs>

## Delete a file or directory

Deletes a file or an empty directory. Set `recursive` to delete a directory and its contents. A non-empty directory fails without the flag. A missing path is not found.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
await sandbox.filesystem.remove("/tmp/note.txt");
await sandbox.filesystem.remove("/tmp/kit-files", { recursive: true });
```

  </Tab>
  <Tab value="Go">

```go
import "github.com/sandbox-kit/kit/sdks/go/sandbox"

files := instance.Filesystem()
if err := files.Remove(ctx, "/tmp/note.txt", nil); err != nil {
	return err
}
if err := files.Remove(ctx, "/tmp/kit-files", &sandbox.RemoveOptions{
	Recursive: sandbox.Value(true),
}); err != nil {
	return err
}
```

  </Tab>
</Tabs>
