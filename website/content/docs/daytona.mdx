## Create

Set `DAYTONA_API_KEY`. Omit create options to use Daytona's default snapshot.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
import { daytona } from "@sandbox-kit/daytona";
import { Client } from "@sandbox-kit/sandbox";

await using client = new Client({
  provider: daytona(),
  auth: { apiKey: { key: process.env.DAYTONA_API_KEY! } },
  timeout: 120_000,
});

const sandbox = await client.create();
console.log(sandbox.id);
```

`timeout` is milliseconds. Prefer `await using`; otherwise call `await client.close()` when finished.

  </Tab>
  <Tab value="Go">

```go
package main

import (
	"context"
	"fmt"
	"os"
	"time"

	"github.com/sandbox-kit/kit/sdks/go/providers/daytona"
	"github.com/sandbox-kit/kit/sdks/go/sandbox"
)

func main() {
	client, err := sandbox.NewClient(daytona.New(), &sandbox.Config{
		Auth: &sandbox.AuthConfig{Credentials: &sandbox.APIKey{
			ApiKey: &sandbox.APIKeyCredentials{Key: os.Getenv("DAYTONA_API_KEY")},
		}},
		Timeout: sandbox.Duration(2 * time.Minute),
	})
	if err != nil {
		panic(err)
	}
	defer client.Close(context.Background())

	instance, err := client.Create(context.Background(), nil)
	if err != nil {
		panic(err)
	}
	fmt.Println(instance.ID())
}
```

Optional strings use `sandbox.Value`.

  </Tab>
</Tabs>

Omit `auth` to let the Daytona SDK pick credentials from its environment. Closing the client does not delete the sandbox.

## Configuration

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

| Setting      | Field                    |
| ------------ | ------------------------ |
| API URL      | `endpoint`               |
| Target       | `region`                 |
| Organization | `scope.organizationId`   |
| Bearer token | `auth.bearerToken.token` |

```ts
await using client = new Client({
  provider: daytona(),
  auth: { apiKey: { key: process.env.DAYTONA_API_KEY! } },
  endpoint: "https://app.daytona.io/api", // default; HTTPS required remotely
  region: process.env.DAYTONA_TARGET, // optional target
  scope: { organizationId: process.env.DAYTONA_ORG_ID },
  timeout: 120_000,
});
```

Bearer token auth:

```ts
await using client = new Client({
  provider: daytona(),
  auth: { bearerToken: { token: process.env.DAYTONA_JWT! } },
  scope: { organizationId: process.env.DAYTONA_ORG_ID! },
  timeout: 120_000,
});
```

  </Tab>
  <Tab value="Go">

| Setting      | Field                  |
| ------------ | ---------------------- |
| API URL      | `Config.Endpoint`      |
| Target       | `Config.Region`        |
| Organization | `Scope.OrganizationId` |
| Bearer token | `BearerToken`          |

```go
config := &sandbox.Config{
	Auth: &sandbox.AuthConfig{Credentials: &sandbox.APIKey{
		ApiKey: &sandbox.APIKeyCredentials{Key: os.Getenv("DAYTONA_API_KEY")},
	}},
	Endpoint: sandbox.Value("https://app.daytona.io/api"), // default; HTTPS remotely
	Region:   sandbox.Value(os.Getenv("DAYTONA_TARGET")),
	Scope: &sandbox.Scope{
		OrganizationId: sandbox.Value(os.Getenv("DAYTONA_ORG_ID")),
	},
	Timeout: sandbox.Duration(2 * time.Minute),
}
client, err := sandbox.NewClient(daytona.New(), config)
```

Bearer token auth:

```go
config := &sandbox.Config{
	Auth: &sandbox.AuthConfig{Credentials: &sandbox.BearerToken{
		BearerToken: &sandbox.BearerTokenCredentials{Token: os.Getenv("DAYTONA_JWT")},
	}},
	Scope: &sandbox.Scope{
		OrganizationId: sandbox.Value(os.Getenv("DAYTONA_ORG_ID")),
	},
	Timeout: sandbox.Duration(2 * time.Minute),
}
client, err := sandbox.NewClient(daytona.New(), config)
```

  </Tab>
</Tabs>

Default API URL: `https://app.daytona.io/api`. Remote URLs need HTTPS; HTTP is allowed for localhost. Bearer tokens need an organization id. Full rules: [Configuration](/docs/configuration).

## What works

| Area      | Notes                                                       |
| --------- | ----------------------------------------------------------- |
| Create    | Default snapshot, named snapshot, or image (with resources) |
| Open      | `get` — verified. `attach` is unsupported                   |
| Lifecycle | `refresh`, `start`, `stop`, `pause`, `archive`, `delete`    |
| Files     | Filesystem methods — [Filesystem](/docs/filesystem)         |
| Process   | `run` — [Run a command](/docs/process)                      |

CPU is whole cores. Memory and disk are whole GiB expressed as MiB. Resource overrides require an image source.
