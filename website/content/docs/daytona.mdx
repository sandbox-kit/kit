Provider package for Daytona sandboxes. Default create uses Daytona's default snapshot. Native SDK: Daytona v0.225.0.

## Create

Set `DAYTONA_API_KEY`.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
import { daytona } from "@sandbox-kit/daytona";
import { Client } from "@sandbox-kit/sandbox";

await using client = new Client({
  provider: daytona(),
  auth: { apiKey: { key: process.env.DAYTONA_API_KEY! } },
  timeout: 120_000,
});

const sandbox = await client.create();
console.log(sandbox.id);
```

`timeout` is milliseconds. Prefer `await using`; otherwise `await client.close()` in `finally`.

  </Tab>
  <Tab value="Go">

```go
package main

import (
	"context"
	"fmt"
	"os"
	"time"

	"github.com/sandbox-kit/kit/sdks/go/providers/daytona"
	"github.com/sandbox-kit/kit/sdks/go/sandbox"
)

func main() {
	client, err := sandbox.NewClient(daytona.New(), &sandbox.Config{
		Auth: &sandbox.AuthConfig{Credentials: &sandbox.APIKey{
			ApiKey: &sandbox.APIKeyCredentials{Key: os.Getenv("DAYTONA_API_KEY")},
		}},
		Timeout: sandbox.Duration(2 * time.Minute),
	})
	if err != nil {
		panic(err)
	}
	defer client.Close(context.Background())

	instance, err := client.Create(context.Background(), nil)
	if err != nil {
		panic(err)
	}
	fmt.Println(instance.ID())
}
```

Nil create options → default snapshot. Optional strings use `sandbox.Value`.

  </Tab>
</Tabs>

Omit `auth` to let the Daytona SDK resolve credentials from its environment. Closing the client does not delete the sandbox.

## Configuration

| Setting      | TypeScript               | Go                     |
| ------------ | ------------------------ | ---------------------- |
| API URL      | `endpoint`               | `Config.Endpoint`      |
| Target       | `region`                 | `Config.Region`        |
| Organization | `scope.organizationId`   | `Scope.OrganizationId` |
| Bearer token | `auth.bearerToken.token` | `BearerToken`          |

Default API URL: `https://app.daytona.io/api`. Remote URLs require HTTPS. HTTP is allowed for localhost/loopback. Bearer tokens require an organization id. Full rules: [Configuration](/docs/configuration).

## Operations

| Area      | Support                                                           |
| --------- | ----------------------------------------------------------------- |
| Create    | Default snapshot, named snapshot, or image (+ resources)          |
| Open      | `get` (verified). `attach` unsupported                            |
| Lifecycle | `refresh`, `start`, `stop`, `pause`, `archive`, `delete`, `close` |
| Files     | Full filesystem API — [Filesystem](/docs/filesystem)              |
| Process   | `run` — [Run a command](/docs/process)                            |

CPU: whole cores. Memory/disk: whole GiB as MiB. Resource overrides require an image source.
