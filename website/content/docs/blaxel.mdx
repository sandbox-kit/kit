## Create

Set `BL_API_KEY` and `BL_WORKSPACE`. Create requires a Blaxel-valid name
(lowercase alphanumeric with single hyphens, at most 49 characters) and an
image. Set `region` on the client (default examples use `us-pdx-1`).

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
import { blaxel } from "@sandbox-kit/blaxel";
import { Client } from "@sandbox-kit/sandbox";

await using client = new Client({
  provider: blaxel(),
  auth: { apiKey: { key: process.env.BL_API_KEY! } },
  scope: { workspace: process.env.BL_WORKSPACE! },
  region: process.env.BL_REGION || "us-pdx-1",
  timeout: 120_000,
});

const sandbox = await client.create({
  name: "kit-example",
  source: { image: { reference: "blaxel/base-image:latest" } },
});
console.log(sandbox.id);
```

`timeout` is milliseconds. Prefer `await using`; otherwise call `await client.close()` when finished.

  </Tab>
  <Tab value="Go">

```go
package main

import (
	"context"
	"fmt"
	"os"
	"time"

	"github.com/sandbox-kit/kit/sdks/go/providers/blaxel"
	"github.com/sandbox-kit/kit/sdks/go/sandbox"
)

func main() {
	client, err := sandbox.NewClient(blaxel.New(), &sandbox.Config{
		Auth: &sandbox.AuthConfig{Credentials: &sandbox.APIKey{
			ApiKey: &sandbox.APIKeyCredentials{Key: os.Getenv("BL_API_KEY")},
		}},
		Scope: &sandbox.Scope{
			Workspace: sandbox.Value(os.Getenv("BL_WORKSPACE")),
		},
		Region:  sandbox.Value("us-pdx-1"),
		Timeout: sandbox.Duration(2 * time.Minute),
	})
	if err != nil {
		panic(err)
	}
	defer client.Close(context.Background())

	instance, err := client.Create(context.Background(), &sandbox.CreateOptions{
		Name: sandbox.Value("kit-example"),
		Source: &sandbox.SandboxSource{Kind: &sandbox.Image{
			Image: &sandbox.ImageSource{Reference: "blaxel/base-image:latest"},
		}},
	})
	if err != nil {
		panic(err)
	}
	fmt.Println(instance.ID())
}
```

Optional strings use `sandbox.Value`.

  </Tab>
</Tabs>

Omit `auth` and `scope.workspace` to let the Blaxel SDK pick credentials from its environment (`BL_API_KEY`, `BL_WORKSPACE`). `region` is still required for create. `endpoint` is rejected. Closing the client does not delete the sandbox.

## Configuration

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

| Setting        | Notes                                                                           |
| -------------- | ------------------------------------------------------------------------------- |
| API key        | `auth.apiKey`                                                                   |
| Omitted `auth` | Blaxel SDK environment / CLI credentials                                        |
| Workspace      | `scope.workspace` — required for create when auth is set explicitly, or via env |
| Region         | `region` — required for create                                                  |
| Endpoint       | Unsupported                                                                     |

```ts
await using client = new Client({
  provider: blaxel(),
  auth: { apiKey: { key: process.env.BL_API_KEY! } },
  scope: { workspace: process.env.BL_WORKSPACE! },
  region: process.env.BL_REGION || "us-pdx-1",
  timeout: 120_000,
});
```

  </Tab>
  <Tab value="Go">

| Setting   | Notes                                 |
| --------- | ------------------------------------- |
| API key   | `Auth` with `APIKey`                  |
| Workspace | `Scope.Workspace`                     |
| Region    | `Config.Region` — required for create |
| Endpoint  | Unsupported                           |

```go
config := &sandbox.Config{
	Auth: &sandbox.AuthConfig{Credentials: &sandbox.APIKey{
		ApiKey: &sandbox.APIKeyCredentials{Key: os.Getenv("BL_API_KEY")},
	}},
	Scope: &sandbox.Scope{
		Workspace: sandbox.Value(os.Getenv("BL_WORKSPACE")),
	},
	Region:  sandbox.Value("us-pdx-1"),
	Timeout: sandbox.Duration(2 * time.Minute),
}
client, err := sandbox.NewClient(blaxel.New(), config)
```

  </Tab>
</Tabs>

Token-pair, bearer, and OAuth client modes are rejected. Scope fields other than workspace are rejected. TypeScript: `@blaxel/core` stores credentials in process-global `settings` — use one Blaxel Kit client, or one credential set, per process. Full rules: [Configuration](/docs/configuration).

## What works

| Area      | Notes                                                                          |
| --------- | ------------------------------------------------------------------------------ |
| Create    | Valid name + image; memory 1:1, labels, env, ports, outbound domains, TTL/idle |
| Volumes   | Not in Kit create; no portable volume fields                                   |
| Open      | `get` / `refresh` by sandbox name                                              |
| Lifecycle | `delete`, `close` — no start/stop/pause/archive/terminate/attach               |
| Files     | Filesystem methods — [Filesystem](/docs/filesystem)                            |
| Process   | Blocking `run` — [Run a command](/docs/process)                                |

`resources.memoryMib` / `memory_mib` maps 1:1 onto Blaxel's memory field.
Blaxel labels that integer MB; Kit does not convert. Blaxel derives CPU from
memory, so CPU and disk overrides are rejected. Default port transport leaves
the protocol to Blaxel (HTTP); plain maps to TCP; TLS maps to TLS; HTTP/2 over
TLS is rejected. Client `timeout` is the Kit create/operation deadline.
`@blaxel/core`'s native creation timeout (1–50s) is not forwarded; the Go SDK
has no equivalent. Ready wait and readiness probes are unsupported.
