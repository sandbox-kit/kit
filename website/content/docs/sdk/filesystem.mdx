---
title: Filesystem
description: Read, write, copy, list, stat, and remove files in a sandbox.
---

Paths inside the sandbox must be absolute. Local paths for copy may be relative. Omitted timeouts use the client default.

<Note>
  <ForLanguage id="typescript">Access as `sandbox.filesystem`.</ForLanguage>
  <ForLanguage id="go">Access as `instance.Filesystem()`.</ForLanguage>
</Note>

## Methods

### Read a file

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
readFile(path: string, options?: FileReadOptions & OperationOptions): Promise<Uint8Array>
```

Returns the bytes of the file at `path`.

**Parameters**

| Name       | Type                                         | Description           |
| ---------- | -------------------------------------------- | --------------------- |
| `path`     | `string`                                     | Absolute sandbox path |
| `options?` | `{ timeout?: number; signal?: AbortSignal }` | Call deadline         |

**Returns**

`Promise<Uint8Array>` — file contents

**Example**

```ts
const bytes = await sandbox.filesystem.readFile("/tmp/note.txt");
console.log(new TextDecoder().decode(bytes));
```

  </Tab>
  <Tab value="Go">

```go
func (f *Filesystem) ReadFile(ctx context.Context, path string, options *FileReadOptions) ([]byte, error)
```

Returns the bytes of the file at `path`.

**Parameters**

| Name      | Type               | Description               |
| --------- | ------------------ | ------------------------- |
| `ctx`     | `context.Context`  | Cancellation and deadline |
| `path`    | `string`           | Absolute sandbox path     |
| `options` | `*FileReadOptions` | Optional `Timeout`        |

**Returns**

`([]byte, error)`

**Example**

```go
data, err := instance.Filesystem().ReadFile(ctx, "/tmp/note.txt", nil)
```


`Promise<void>`

**Example**

### Make a directory

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
makeDirectory(path: string, options?: MakeDirectoryOptions & OperationOptions): Promise<void>
```

Creates the directory at `path`. An omitted `parents` flag is `true` (create missing parents).

**Parameters**

| Name       | Type                                       | Description               |
| ---------- | ------------------------------------------ | ------------------------- |
| `path`     | `string`                                   | Absolute sandbox path     |
| `options?` | `{ parents?: boolean; timeout?; signal? }` | Parents flag and deadline |

**Returns**

`Promise<void>`

<ForProvider id="daytona">
  Daytona rejects `parents: false` before the call (field `parents`) and errors
  if the directory already exists. Transfer timeouts must be whole seconds;
  omit/zero passes `0` so Daytona does not apply its 30-minute upload/download
  default.
</ForProvider>

<ForProvider id="modal">
  Modal accepts a directory that already exists. With `parents: false`, the
  parent must already exist. Fractional-millisecond deadlines are allowed on
  filesystem calls.
</ForProvider>

<ForProvider id="blaxel">
  Blaxel creates missing parents when `parents` is omitted or `true`. It does
  not support `parents: false` (field `parents`).
</ForProvider>

  </Tab>

### Stat a path

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
stat(path: string, options?: StatOptions & OperationOptions): Promise<FileInfo>
```

Returns metadata for one path. A symlink result describes the symlink.

**Returns**

`Promise<FileInfo>`

**Example**

```ts
const info = await sandbox.filesystem.stat("/tmp/note.txt");
// info: { name, path, type, size, mode?, permissions?, owner?, group?,
//         modifiedAt?, symlinkTarget? }
console.log(info);
```

<ForProvider id="blaxel">
  You get `type` (file or directory), `size`, and usually `permissions`,
  `owner`, `group`, and `modifiedAt`.
</ForProvider>

### Remove a path

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
remove(path: string, options?: RemoveOptions & OperationOptions): Promise<void>
```

Removes a file, or a directory when `recursive` is set. An omitted `recursive` flag removes a file or an empty directory.

**Parameters**

| Name       | Type                                         | Description                 |
| ---------- | -------------------------------------------- | --------------------------- |

| `options?` | `{ recursive?: boolean; timeout?; signal? }` | Recursive flag and deadline |

**Returns**

`Promise<void>`

**Example**

```ts
await sandbox.filesystem.remove("/tmp/dir", { recursive: true });
```

## FileInfo

Metadata for one file, directory, or symlink.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

| Field           | Description                                                         |
| --------------- | ------------------------------------------------------------------- |
| `name`          | Base name                                                           |
| `path`          | Absolute path in the sandbox                                        |
| `type`          | [`FileType`](/docs/sdk/enums#filetype): file, directory, or symlink |
| `size`          | Size in bytes                                                       |
| `mode`          | Unix mode string when reported (for example `0644`)                 |
| `permissions`   | Symbolic permissions when reported                                  |
| `owner`         | Ownership when reported                                             |
| `group`         | Group when reported                                                 |
| `modifiedAt`    | Last modification time when reported                                |
| `symlinkTarget` | Target path when the entry is a symlink                             |
