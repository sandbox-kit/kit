title: Sandbox
description: Handle for one sandbox — lifecycle, info, filesystem, and process.
---

Handle from [`Client.create`](/docs/sdk/client#create), [`get`](/docs/sdk/client#get), or [`attach`](/docs/sdk/client#attach). Lifecycle methods that return info also update the handle. `close` only drops local resources—the cloud sandbox keeps running. Call `supports` before a lifecycle method that might be unavailable.

## Operation options

Shared call options for TypeScript lifecycle and filesystem/process calls.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
interface OperationOptions {
  signal?: AbortSignal;
  timeout?: number; // milliseconds
}

type StopCallOptions = OperationOptions & { force?: boolean };
type TerminateCallOptions = OperationOptions & { wait?: boolean };
type DeleteCallOptions = OperationOptions & { wait?: boolean };
```

| Field     | Description                                                                  |
| --------- | ---------------------------------------------------------------------------- |
| `signal`  | Abort the wait. The handle stays busy until the in-flight call finishes.     |
| `timeout` | Deadline for this call (ms). Omitted → client default. `0` → no deadline.    |
| `force`   | On stop: request an immediate stop.                                          |
| `wait`    | On terminate/delete: wait until the operation finishes.                      |

  </Tab>
  <Tab value="Go">

Lifecycle option messages carry `Timeout *durationpb.Duration` (via `sandbox.Duration`). `StopOptions` adds `Force *bool`. `TerminateOptions` and `DeleteOptions` add `Wait *bool`.

| Field     | Description                                                                |
| --------- | -------------------------------------------------------------------------- |
| `Timeout` | Deadline for this call. Nil → client default. Explicit zero → no deadline. |
| `Force`   | On stop: `Value(true)` requests an immediate stop.                         |
| `Wait`    | On terminate/delete: wait until finished.                                  |

  </Tab>
</Tabs>
