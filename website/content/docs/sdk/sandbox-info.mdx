---
title: SandboxInfo
description: Metadata returned by info and lifecycle calls.
---

Returned by info and many lifecycle methods. Values are a **copy**; mutating them does not change the handle. Reported resources can differ from what you requested.

<Note>
  <ForLanguage id="typescript">
    From [`sandbox.info()`](/docs/sdk/sandbox#read-metadata).
  </ForLanguage>
  <ForLanguage id="go">
    From [`instance.Info()`](/docs/sdk/sandbox#read-metadata).
  </ForLanguage>
</Note>

## Fields

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

| Field              | Description                                              |
| ------------------ | -------------------------------------------------------- |
| `id`               | Sandbox identifier                                       |
| `provider`         | Provider identifier                                      |
| `name`             | Display name when reported                               |
| `providerState`    | Provider-specific status string; prefer portable `state` |
| `region`           | Region when reported                                     |
| `isolation`        | Reported isolation config                                |
| `resources`        | Reported size (`cpuCores`, `memoryMib`, …)               |
| `labels`           | Labels when reported                                     |
| `createdAt`        | Creation time when reported                              |
| `providerMetadata` | Extra provider metadata object                           |
| `state`            | Portable [`SandboxState`](/docs/sdk/enums#sandboxstate)  |
| `terminal`         | Whether the lifecycle is permanently complete            |

<ForProvider id="blaxel">
  `labels` is set only when Blaxel returns them — not copied from the create
  request.
</ForProvider>

**Example**

```ts
const info = sandbox.info();
// info: { id, provider, name?, providerState?, region?, isolation?,
//         resources?, labels, createdAt?, providerMetadata?, state, terminal? }
console.log(info);
```
