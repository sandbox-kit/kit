Creates sandboxes and reopens them.

<ForProvider id="daytona">
  <ForLanguage id="typescript">Reopen with [`get`](#get) by sandbox id.</ForLanguage>
  <ForLanguage id="go">Reopen with [`Get`](#get) by sandbox id.</ForLanguage>
</ForProvider>
<ForProvider id="modal">
  <ForLanguage id="typescript">
    Reopen with [`attach`](#attach) by sandbox id. It does not check that the
    sandbox exists.
  </ForLanguage>
  <ForLanguage id="go">
    Reopen with [`Attach`](#attach) by sandbox id. It does not check that the
    sandbox exists.
  </ForLanguage>
</ForProvider>
<ForProvider id="blaxel">
  <ForLanguage id="typescript">Reopen with [`get`](#get) by create name. Blaxel id is the name.</ForLanguage>
  <ForLanguage id="go">Reopen with [`Get`](#get) by create name. Blaxel id is the name.</ForLanguage>
</ForProvider>

Closing the client only drops the local connection—cloud sandboxes keep running.

## Construction

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
new Client(config: ClientConfig)
```

Creates a client for the selected provider. Throws if config is invalid.

**Parameters**

| Name     | Type                                      | Description                                                                      |
| -------- | ----------------------------------------- | -------------------------------------------------------------------------------- |
| `config` | [`ClientConfig`](/docs/sdk/configuration) | Provider plus shared settings (`auth`, `scope`, `endpoint`, `region`, `timeout`) |

**Returns**

`Client`

**Example**

```ts
import { Client } from "@sandbox-kit/sandbox";

await using client = new Client({
  provider,
  timeout: 120_000, // default client deadline (ms)
});
```

`await using` calls `close` on dispose.

  </Tab>
  <Tab value="Go">

```go
func NewClient(provider Provider, config *Config) (*Client, error)
```

Creates a client for the selected provider. Invalid config returns a nil client and an error.

**Parameters**

| Name       | Type                                 | Description                                                        |
| ---------- | ------------------------------------ | ------------------------------------------------------------------ |
| `provider` | `Provider`                           | Provider constructor from a provider package                       |
| `config`   | [`*Config`](/docs/sdk/configuration) | Shared settings (`Auth`, `Scope`, `Endpoint`, `Region`, `Timeout`) |

**Returns**

`(*Client, error)`

**Example**

```go
client, err := sandbox.NewClient(provider, &sandbox.Config{
	Timeout: sandbox.Duration(2 * time.Minute), // default client deadline
})
if err != nil {
	return err
}
defer client.Close(context.Background())
```

## Methods

### create

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
create(request?: CreateOptions, options?: OperationOptions): Promise<Sandbox>
```

Creates one sandbox and returns its handle.

<ForProvider id="daytona">
  Omit the request (or pass `{}`) to use Daytona's default snapshot.
</ForProvider>
<ForProvider id="modal">
  Pass an `image` source. Empty options are rejected.
</ForProvider>
<ForProvider id="blaxel">
  Pass a Blaxel-valid `name`, an `image` source, and client `region`.
</ForProvider>

**Parameters**

| Name       | Type                                                      | Description                                         |
| ---------- | --------------------------------------------------------- | --------------------------------------------------- |
| `request?` | [`CreateOptions`](/docs/sdk/create-options)               | Create body. Omitted fields keep provider defaults. |
| `options?` | [`OperationOptions`](/docs/sdk/sandbox#operation-options) | Call `timeout` (ms) and optional `signal`           |

**Returns**

`Promise<`[`Sandbox`](/docs/sdk/sandbox)`>` — handle for the new sandbox

**Example**

<ForProvider id="daytona">

```ts
const sandbox = await client.create(
  { source: { image: { reference: "daytonaio/playground:latest" } } },
  { timeout: 60_000 }, // deadline for this call (ms)
);
console.log(sandbox.id);
```

</ForProvider>

<ForProvider id="modal">

```ts
const sandbox = await client.create(
  { source: { image: { reference: "alpine:3.21" } } },
  { timeout: 60_000 }, // deadline for this call (ms)
);
console.log(sandbox.id);
```

</ForProvider>

<ForProvider id="blaxel">

```ts
const sandbox = await client.create(
  {
    name: "kit-example",
    source: { image: { reference: "blaxel/base-image:latest" } },
  },
  { timeout: 60_000 }, // deadline for this call (ms)
);
console.log(sandbox.id);
```

</ForProvider>

  </Tab>
  <Tab value="Go">

```go
func (c *Client) Create(ctx context.Context, request *CreateOptions) (*Sandbox, error)
```

Creates one sandbox and returns its handle.

<ForProvider id="daytona">
  A nil request uses Daytona's default snapshot.
</ForProvider>
<ForProvider id="modal">
  Pass an image source. A nil request is rejected.
</ForProvider>
<ForProvider id="blaxel">
  Pass a Blaxel-valid `Name`, an image source, and client `Region`.
</ForProvider>

**Parameters**

| Name      | Type                                         | Description                   |
| --------- | -------------------------------------------- | ----------------------------- |
| `ctx`     | `context.Context`                            | Cancellation and deadline     |
| `request` | [`*CreateOptions`](/docs/sdk/create-options) | Create body; nil for defaults |

**Returns**

`(*Sandbox, error)` — handle for the new sandbox

**Example**

<ForProvider id="daytona">

```go
instance, err := client.Create(ctx, &sandbox.CreateOptions{
	Source: &sandbox.SandboxSource{Kind: &sandbox.Image{
		Image: &sandbox.ImageSource{Reference: "daytonaio/playground:latest"},
	}},
	Provisioning: &sandbox.ProvisioningOptions{
		Timeout: sandbox.Duration(60 * time.Second), // deadline for this call
	},
})
```

</ForProvider>

<ForProvider id="modal">

