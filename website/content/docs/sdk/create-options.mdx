Request body for [`Client.create`](/docs/sdk/client#create). Omitted fields keep provider defaults. Unsupported fields fail before the provider call.

## CreateOptions

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
type CreateOptions = {
  name?: string;
  source?: SandboxSourceInput;
  runtime?: RuntimeConfig;
  isolation?: IsolationConfig;
  resources?: Resources;
  placement?: Placement;
  environment?: Record<string, string>;
  labels?: Record<string, string>;
  network?: NetworkConfigInput;
  security?: SecurityConfig;
  lifetime?: LifetimePolicyInput;
  provisioning?: ProvisioningOptionsInput;
  readiness?: ReadinessProbeInput;
  observability?: ObservabilityConfig;
};
```

Durations on this type are **milliseconds**. Allowlists under `network` are plain `string[]`.

| Field           | Description                                             |
| --------------- | ------------------------------------------------------- |
| `name`          | Display name. Explicit empty string asks for unnamed.   |
| `source`        | Image, snapshot, warm pool, or provider default         |
| `runtime`       | Language hint, user, working directory, entrypoint, PTY |
| `isolation`     | Isolation class                                         |
| `resources`     | CPU, memory MiB, disk MiB                               |
| `placement`     | Cloud, preferred regions, or target                     |
| `environment`   | Process environment for the sandbox                     |
| `labels`        | Caller labels/tags                                      |
| `network`       | Egress, allowlists, ports, links                        |
| `security`      | Public access, workload identity, secrets               |
| `lifetime`      | Max lifetime and idle/stopped actions                   |
| `provisioning`  | Create deadline, queue timeout, wait condition          |
| `readiness`     | Probe when waiting until ready                          |
| `observability` | Verbose logging / telemetry                             |

**Example**

<ForProvider id="daytona">

```ts
  source: { image: { reference: "daytonaio/playground:latest" } },
  resources: { cpuCores: 1, memoryMib: 512n },
});
```

## Source

Set exactly one variant. Unsupported variants fail before the provider call.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

| Variant           | Description                           |
| ----------------- | ------------------------------------- |
| `image`           | Container image `reference`           |
| `snapshot`        | Snapshot `reference`, optional `kind` |
| `warmPool`        | Warm pool `reference`                 |
| `providerDefault` | Use the account default source        |

  </Tab>
  <Tab value="Go">

| Variant           | Description                           |
| ----------------- | ------------------------------------- |
| `Image`           | Container image `Reference`           |
| `Snapshot`        | Snapshot `Reference`, optional `Kind` |
| `WarmPool`        | Warm pool `Reference`                 |
| `ProviderDefault` | Use the account default source        |

  </Tab>
</Tabs>

<ForProvider id="daytona">
  Daytona accepts `image`, `snapshot`, and `providerDefault` when the account
  allows them. Memory and disk requests must be whole GiB expressed as MiB; CPU
  must be whole cores. Per-request `placement` is rejected—set client `region`
  instead.
</ForProvider>

<ForProvider id="modal">
  Modal requires an `image` source (`providerDefault` is rejected). `diskMib`
  and placement `target` are unsupported. Lifetime supports `maximumLifetime`
  and `idleTerminate` only.
</ForProvider>

<ForProvider id="blaxel">
  Blaxel requires an `image` source and a Blaxel-valid `name` (lowercase
  alphanumeric with single hyphens, at most 49 characters). Client `region` is
  required. Default port transport leaves the protocol to Blaxel (HTTP); plain
  maps to TCP; TLS maps to TLS; HTTP/2 over TLS is rejected. Ports 80, 443, and
  8080 are reserved. Kit create timeout is the local deadline; `@blaxel/core`'s
  native creation timeout is not forwarded.
</ForProvider>

## LifetimePolicy

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

| Field             | Description                                            |
| ----------------- | ------------------------------------------------------ |
| `maximumLifetime` | Cap on how long the sandbox may exist                  |
| `ephemeral`       | Prefer deletion when the sandbox stops, when supported |
| `idleTerminate`   | End after idle                                         |
| `idleStop`        | Stop after idle                                        |
| `idlePause`       | Pause after idle                                       |
| `stoppedArchive`  | Archive after stop                                     |
| `stoppedDelete`   | Delete after stop                                      |

<ForProvider id="daytona">
  Daytona maps lifetime delays as **whole minutes**. Supported policies include
  ephemeral, idle stop/pause, and stopped archive/delete (`stoppedArchive` max
  43200 minutes). `idleTerminate` is not used.
</ForProvider>

<ForProvider id="modal">
  Modal supports `maximumLifetime` (whole seconds, 1…86400) and `idleTerminate`
  only. Ephemeral, idle stop/pause, and stopped archive/delete are rejected.
</ForProvider>

| `waitFor`      | [`WaitCondition`](/docs/sdk/enums#waitcondition) before returning |

<ForProvider id="daytona">
