title: Client
description: Construct a client; create, get or attach, and close.

Creates sandboxes and reopens them by id (`get` or `attach`). Closing the client only drops the local connection—cloud sandboxes keep running.

## Construction

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
new Client(config: ClientConfig)
```

Validates config and initializes the selected provider. Throws on invalid config.

**Parameters**

| Name     | Type                                      | Description                                                                      |
| -------- | ----------------------------------------- | -------------------------------------------------------------------------------- |
| `config` | [`ClientConfig`](/docs/api/configuration) | Provider plus shared settings (`auth`, `scope`, `endpoint`, `region`, `timeout`) |

**Returns**

`Client`

**Example**

```ts
import { Client } from "@sandbox-kit/sandbox";

await using client = new Client({
  provider,
  timeout: 120_000, // default client deadline (ms)
});
```

`await using` calls `close` on dispose.

  </Tab>
  <Tab value="Go">

```go
func NewClient(provider Provider, config *Config) (*Client, error)
```

Validates config and initializes the provider. Invalid config returns a nil client and an error.

**Parameters**

| Name       | Type                                 | Description                                                        |
| ---------- | ------------------------------------ | ------------------------------------------------------------------ |
| `provider` | `Provider`                           | Provider constructor from a provider package                       |
| `config`   | [`*Config`](/docs/api/configuration) | Shared settings (`Auth`, `Scope`, `Endpoint`, `Region`, `Timeout`) |

**Returns**

`(*Client, error)`

**Example**

```go
client, err := sandbox.NewClient(provider, &sandbox.Config{
	Timeout: sandbox.Duration(2 * time.Minute), // default client deadline
})
if err != nil {
	return err
}
defer client.Close(context.Background())
```

## Methods

### create

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
create(request?: CreateOptions, options?: OperationOptions): Promise<Sandbox>
```

Creates one sandbox and returns its handle. Omit the request (or pass `{}`) to use provider defaults.

**Parameters**

| Name       | Type                                                      | Description                                         |
| ---------- | --------------------------------------------------------- | --------------------------------------------------- |
| `request?` | [`CreateOptions`](/docs/api/create-options)               | Create body. Omitted fields keep provider defaults. |
| `options?` | [`OperationOptions`](/docs/api/sandbox#operation-options) | Call `timeout` (ms) and optional `signal`           |

**Returns**

`Promise<`[`Sandbox`](/docs/api/sandbox)`>` — handle for the new sandbox

**Example**

<ForProvider id="daytona">

```ts
const sandbox = await client.create(
  { source: { image: { reference: "daytonaio/playground:latest" } } },
  { timeout: 60_000 }, // deadline for this call (ms)
);
console.log(sandbox.id);
```

</ForProvider>

<ForProvider id="modal">

```ts
const sandbox = await client.create(
  { source: { image: { reference: "alpine:3.21" } } },
  { timeout: 60_000 }, // deadline for this call (ms)

```

</ForProvider>

### get

Looks up a sandbox by id and returns a handle the provider has verified.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
get(id: string, options?: OperationOptions): Promise<Sandbox>
```

**Parameters**

| Name       | Type               | Description             |
| ---------- | ------------------ | ----------------------- |
| `id`       | `string`           | Sandbox identifier      |
| `options?` | `OperationOptions` | Call timeout and signal |

**Returns**

`Promise<Sandbox>`

**Example**

```ts
const sandbox = await client.get(knownId);
const info = sandbox.info();
// info: { id, provider, name?, providerState?, region?, isolation?,
//         resources?, labels, createdAt?, providerMetadata?, state, terminal? }
console.log(info);
```

  </Tab>
  <Tab value="Go">

```go

```

**Parameters**

| Name  | Type              | Description               |
| ----- | ----------------- | ------------------------- |
| `ctx` | `context.Context` | Cancellation and deadline |
| `id`  | `string`          | Sandbox identifier        |

**Returns**

`(*Sandbox, error)`

**Example**

```go
instance, err := client.Get(ctx, knownID)
// Info(): Id, Provider, Name, ProviderState, Region, Isolation,
//         Resources, Labels, CreatedAt, ProviderMetadata, State, Terminal
```
