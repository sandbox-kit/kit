Failed calls surface a typed error. Kinds are categories, not retry advice. Handling patterns: [Errors guide](/docs/errors).

## Shape

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
class SandboxError extends Error {
  kind: ErrorKind;
  provider: string;
  operation: string;
  field: string;
  rule?: string;
  statusCode?: number;
  providerCode?: string;
  providerSource?: string;
  // cause?: unknown — provider error when present
}
```

Throws from the client and sandbox handle.

| Field            | Description                                                                                  |
| ---------------- | -------------------------------------------------------------------------------------------- |
| `kind`           | [`ErrorKind`](#errorkind) category                                                           |
| `provider`       | Provider id, or empty for local failures                                                     |
| `operation`      | Call name (`create`, `initialize`, `run`, …)                                                 |
| `field`          | Canonical path of the rejected setting (for example `resources.cpu_cores`). Empty when none. |
| `message`        | Human-readable explanation                                                                   |
| `rule`           | Stable validation/policy id when applicable                                                  |
| `statusCode`     | HTTP/transport status when reported                                                          |
| `providerCode`   | Provider's own error code when reported                                                      |
| `providerSource` | Provider component when reported                                                             |

Exported field-path constants (for example `CreateFieldResourcesCpuCores`) match `field` for comparisons.

**Example**

```ts
import { ErrorKind, SandboxError } from "@sandbox-kit/sandbox";

try {
  await client.create(request);
} catch (error) {
  if (!(error instanceof SandboxError)) throw error;
  // error: { kind, provider, operation, field, message, rule?,
  //          statusCode?, providerCode?, providerSource?, cause? }
  console.error(error);
  if (error.kind === ErrorKind.InvalidArgument) {
    // fix the field named by error.field
  }
}
```

```go
type Error struct {
	Kind           ErrorKind
	Provider       string
	Operation      string
	Field          string
	Message        string
	StatusCode     *uint32
	ProviderCode   *string
	ProviderSource *string
	Rule           *string
	// Unwrap() returns the provider/validator cause when present
}
```

Use `errors.As(err, &detail)` to read fields.

| Field            | Description                                                                                  |
| ---------------- | -------------------------------------------------------------------------------------------- |
| `Kind`           | [`ErrorKind`](#errorkind) category                                                           |
| `Provider`       | Provider id, or empty for local failures                                                     |
| `Operation`      | Call name (`create`, `initialize`, `run`, …)                                                 |
| `Field`          | Canonical path of the rejected setting (for example `resources.cpu_cores`). Empty when none. |
| `Message`        | Human-readable explanation                                                                   |
| `Rule`           | Stable validation/policy id when applicable                                                  |
| `StatusCode`     | HTTP/transport status when reported                                                          |
| `ProviderCode`   | Provider's own error code when reported                                                      |
| `ProviderSource` | Provider component when reported                                                             |

Exported field-path constants (for example `CreateFieldResourcesCpuCores`) match `Field` for comparisons.

**Example**

```go
var detail *sandbox.Error
if errors.As(err, &detail) {
	// detail: Kind, Provider, Operation, Field, Message, StatusCode,
	//         ProviderCode, ProviderSource, Rule (+ Unwrap cause)
	fmt.Println(detail)
	if detail.Kind == sandbox.ErrorKindInvalidArgument {
		// fix the field named by detail.Field
	}
}
```

## ErrorKind

| Kind                 | Description                                            |
| -------------------- | ------------------------------------------------------ |
| `InvalidArgument`    | The request shape is wrong                             |
| `Unsupported`        | This provider does not implement the call or the field |
| `Authentication`     | Credentials were rejected                              |
| `PermissionDenied`   | The account cannot perform this operation              |
| `NotFound`           | The sandbox or file path was not found                 |
| `AlreadyExists`      | The named resource already exists                      |
| `Conflict`           | Current state rejects this operation                   |
| `RateLimited`        | Provider rate limit reached                            |
| `ResourceExhausted`  | Provider quota or capacity reached                     |
| `Timeout`            | The deadline fired                                     |
| `Canceled`           | The caller canceled the operation                      |
| `Unavailable`        | The provider could not be reached                      |
| `InvalidResponse`    | The provider response cannot be used                   |
| `Internal`           | Unclassified failure                                   |
| `FailedPrecondition` | Client or sandbox is not in a usable state             |
| `Unknown`            | Does not match a known category                        |
