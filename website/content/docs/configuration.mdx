Pass a provider and config at construction. Changing the config object afterward does not update a running client. Invalid config: [Errors](/docs/errors#invalid-config).

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
import { Client } from "@sandbox-kit/sandbox";

await using client = new Client({
  provider,
  timeout: 120_000, // default client deadline (ms)
});
```

  </Tab>
  <Tab value="Go">

```go
import (
	"time"

	"github.com/sandbox-kit/kit/sdks/go/sandbox"
)

client, err := sandbox.NewClient(provider, &sandbox.Config{
	Timeout: sandbox.Duration(2 * time.Minute), // default client deadline
})
if err != nil {
	return err
}
```

  </Tab>
</Tabs>

| Field      | Purpose                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------- |
| `provider` | Provider constructor                                                                        |
| `auth`     | One of `apiKey`, `tokenPair`, `bearerToken`, `oauthRefresh`. Omit to use provider env creds |
| `scope`    | App, environment, organization, or workspace                                                |
| `endpoint` | Provider endpoint URL override                                                              |
| `region`   | Target / default placement                                                                  |
| `timeout`  | Default deadline for calls that omit their own                                              |

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

| Setting      | What to pass                                      |
| ------------ | ------------------------------------------------- |
| `apiKey`     | `auth.apiKey.key`                                 |
| Bearer token | `auth.bearerToken.token`, plus an organization id |
| Endpoint     | `endpoint`. Default `https://app.daytona.io/api`  |
| Target       | `region`. Omit for the default target             |
| Organization | `scope.organizationId`                            |

```ts
await using client = new Client({
  provider: daytona(),
  auth: { bearerToken: { token: process.env.DAYTONA_JWT! } },
  scope: { organizationId: process.env.DAYTONA_ORG_ID! },
  endpoint: "https://app.daytona.io/api",
  region: process.env.DAYTONA_TARGET,
  timeout: 120_000,
});
```

  </Tab>
  <Tab value="Go">

| Setting      | What to pass                                            |
| ------------ | ------------------------------------------------------- |
| `APIKey`     | `APIKey`                                                |
| Bearer token | `BearerToken`, plus an organization id                  |
| Endpoint     | `Config.Endpoint`. Default `https://app.daytona.io/api` |
| Target       | `Config.Region`. Omit for the default target            |
| Organization | `Scope.OrganizationId`                                  |

```go
config := &sandbox.Config{
	Auth: &sandbox.AuthConfig{Credentials: &sandbox.BearerToken{
		BearerToken: &sandbox.BearerTokenCredentials{Token: os.Getenv("DAYTONA_JWT")},
	}},
	Scope: &sandbox.Scope{
		OrganizationId: sandbox.Value(os.Getenv("DAYTONA_ORG_ID")),
	},
	Endpoint: sandbox.Value("https://app.daytona.io/api"),
	Region:   sandbox.Value(os.Getenv("DAYTONA_TARGET")),
	Timeout:  sandbox.Duration(2 * time.Minute),
}
client, err := sandbox.NewClient(daytona.New(), config)
```

  </Tab>
</Tabs>

Remote endpoints must be HTTPS. HTTP is fine for localhost and loopback. URLs with a username, password, or fragment are rejected. Sandbox Kit does not read the Daytona URL from the environment.

## Timeouts

`timeout` on the client is the default deadline. Create and lifecycle calls can override it.

Explicit zero means no deadline from the client. A context deadline or abort signal that fires earlier still wins.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

<ForProvider id="daytona">

```ts
await using client = new Client({
  provider: daytona(),
  timeout: 120_000, // default for calls that omit timeout
});

const sandbox = await client.create(
  { source: { image: { reference: "daytonaio/playground:latest" } } },
  { timeout: 60_000 }, // override for this call; 0 = no deadline
);
```

</ForProvider>

  Daytona keeps its 60-second default for create, start, stop, pause, and delete
  when you omit the timeout or pass zero. Fractional-second Daytona timeouts are
  rejected.
