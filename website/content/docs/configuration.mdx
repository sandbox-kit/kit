title: Configuration
description: Auth, scope, endpoint, region, and default timeouts on Client construction.
---

Pass provider + config at construction. Later mutations of the config object do not affect a running client. TypeScript throws on invalid config; Go returns `(*Client, error)`.

| Field      | Purpose                                                                                               |
| ---------- | ----------------------------------------------------------------------------------------------------- |
| `provider` | `daytona()` / `modal()` (or Go `New()`)                                                               |
| `auth`     | One of `apiKey`, `tokenPair`, `bearerToken`, `oauthRefresh`. Omit to use provider SDK env credentials |
| `scope`    | App, environment, or organization                                                                     |
| `endpoint` | API URL when the provider allows it                                                                   |
| `region`   | Target / default placement                                                                            |
| `timeout`  | Default deadline (TS: ms, Go: `sandbox.Duration`)                                                     |

Switch Daytona or Modal above for auth and scope samples. First client walkthrough: [Daytona](/docs/daytona) or [Modal](/docs/modal).

```go
config := &sandbox.Config{
	Auth: &sandbox.AuthConfig{Credentials: &sandbox.APIKey{
		ApiKey: &sandbox.APIKeyCredentials{Key: os.Getenv("DAYTONA_API_KEY")},
	}},
	Timeout: sandbox.Duration(2 * time.Minute),
}

	config.Region = sandbox.Value(target)
}
client, err := sandbox.NewClient(daytona.New(), config)
```

<ForProvider id="daytona">

| Setting      | What to pass                                                         |
| ------------ | -------------------------------------------------------------------- |
| API key      | `auth.apiKey.key` / `APIKey`                                         |
| Bearer token | `auth.bearerToken.token` / `BearerToken`, plus an organization id    |
| Endpoint     | `endpoint` / `Config.Endpoint`. Default `https://app.daytona.io/api` |
| Target       | `region` / `Config.Region`. Leave it unset for the default target    |
| Organization | `scope.organizationId` / `Scope.OrganizationId`                      |

A remote endpoint uses HTTPS. HTTP is accepted for localhost and loopback. A URL with a username, password, or fragment is rejected. Sandbox Kit does not read the Daytona URL from the environment.

</ForProvider>

<ForProvider id="modal">

| Setting       | What to pass                                                             |
| ------------- | ------------------------------------------------------------------------ |
| Token pair    | `auth.tokenPair` / `TokenPair`                                           |
| OAuth refresh | Client id, plus one client secret or one JWT key                         |
| App           | `scope.appName` / `Scope.AppName`, required                              |
| Environment   | `scope.environment` / `Scope.Environment`, often `main`                  |
| Region        | `region` / `Config.Region`. Leave it unset for Modal's default placement |

`endpoint` is rejected. You can still set cloud and region on a single [create](/docs/create) request.

</ForProvider>

## Timeouts

`timeout` on the client is the default deadline. A create request can override it. A lifecycle call can override it again.

Explicit zero adds no deadline of Sandbox Kit's own. A context deadline or an abort signal that arrives earlier still applies.

<ForProvider id="daytona">
  Daytona keeps its 60-second default for create, start, stop, pause, and delete
  when you omit the timeout, and when you pass explicit zero. A Daytona timeout
  that is not a whole number of seconds is rejected.
</ForProvider>

## Credentials

Do not log the config object—it contains secrets. TypeScript configs are plain objects (`JSON.stringify` includes keys).

Construction does not contact the provider. Bad credentials fail on the first create/get/attach. See [Errors](/docs/errors).
