## Units

Account quotas, image names, regions, and capacity are enforced by the provider.

<ForProvider id="daytona">

|           | Daytona                                                               |
| --------- | --------------------------------------------------------------------- |
| Source    | Omit for the default snapshot, or pass a snapshot or an image         |
| CPU       | Whole cores                                                           |
| Memory    | Whole GiB, written as MiB (`4096` is 4 GiB)                           |
| Disk      | Whole GiB, written as MiB                                             |
| Lifetime  | TTL, and stop, pause, archive, or delete policies                     |
| Placement | `region` on the client. A placement block on this request is rejected |

A size override requires an image. A snapshot create keeps the snapshot's size.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
import { PolicyMode } from "@sandbox-kit/sandbox";

await client.create({
  source: { image: { reference: "daytonaio/playground:latest" } },
  resources: {
    cpuCores: 2, // whole cores
    memoryMib: 4096n, // 4 GiB as MiB
    diskMib: 8192n, // 8 GiB as MiB
  },
  lifetime: {
    idlePause: { mode: PolicyMode.Disabled },
    stoppedDelete: { mode: PolicyMode.After, after: 10 * 60_000 },
  },
  runtime: {
    workingDirectory: "/home/daytona",
    entrypoint: ["sleep", "infinity"],
  },
});
```

  </Tab>
  <Tab value="Go">

```go
instance, err := client.Create(ctx, &sandbox.CreateOptions{
	Source: &sandbox.SandboxSource{Kind: &sandbox.Image{
		Image: &sandbox.ImageSource{Reference: "daytonaio/playground:latest"},
	}},
	Resources: &sandbox.Resources{
		CpuCores:  sandbox.Value(2.0),          // whole cores
		MemoryMib: sandbox.Value(uint64(4096)), // 4 GiB as MiB
		DiskMib:   sandbox.Value(uint64(8192)), // 8 GiB as MiB
	},
	Lifetime: &sandbox.LifetimePolicy{
		IdlePause: &sandbox.AutomaticAction{Mode: sandbox.PolicyModeDisabled},
		StoppedDelete: &sandbox.AutomaticAction{
			Mode:  sandbox.PolicyModeAfter,
			After: sandbox.Duration(10 * time.Minute),
		},
	},
	Runtime: &sandbox.RuntimeConfig{
		WorkingDirectory: sandbox.Value("/home/daytona"),
		Entrypoint:       []string{"sleep", "infinity"},
	},
})
```

<ForProvider id="modal">

|           | Modal                                                       |
| --------- | ----------------------------------------------------------- |
| Source    | Registry image, required                                    |
| CPU       | Fractional cores, minimum 0.125, step 0.001                 |
| Memory    | MiB, minimum 128 when set                                   |
| Disk      | Cannot be set                                               |
| Lifetime  | Maximum lifetime and idle termination                       |
| Placement | `placement` on this request. Client `region` is the default |

Pass a registry image. Put the app name on the client, not on this request. Leave a resource out to keep Modal's default.

Name a snapshot by reference (for example `daytona-small`). Set toolbox language and user on `runtime`.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
  source: {
    snapshot: { reference: "daytona-small" },
  },

```

  </Tab>
  <Tab value="Go">

```go
instance, err := client.Create(ctx, &sandbox.CreateOptions{
	Source: &sandbox.SandboxSource{Kind: &sandbox.Snapshot{
		Snapshot: &sandbox.SnapshotSource{Reference: "daytona-small"},
	}},
})
```

  </Tab>

A linked sandbox must be ephemeral; Kit rejects the request otherwise.

Idle stop, idle pause, stopped archive, and stopped delete use `PolicyMode` (`After` / `Disabled`). You cannot combine a positive stop delay with a positive pause delay.

See [Examples](/docs/examples).

</ForProvider>

<ForProvider id="modal">

Set cloud and region on `placement`. A ready wait needs a probe and a positive timeout.

Disk size, an endpoint override, and stop / pause / archive / delete policies are rejected.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
import { WaitCondition } from "@sandbox-kit/sandbox";

await client.create({
  source: { image: { reference: "alpine:3.21" } },
  placement: {
    cloud: "aws",
    regions: ["us-east-1"],
  },
  runtime: { entrypoint: ["sleep", "300"] },
  readiness: { command: { argv: ["true"] } },
  provisioning: { timeout: 120_000, waitFor: WaitCondition.Ready },
});
```

  </Tab>
  <Tab value="Go">

```go
instance, err := client.Create(ctx, &sandbox.CreateOptions{
	Source: &sandbox.SandboxSource{Kind: &sandbox.Image{
		Image: &sandbox.ImageSource{Reference: "alpine:3.21"},
	}},
	Placement: &sandbox.Placement{
		Cloud:   sandbox.Value("aws"),
		Regions: []string{"us-east-1"},
	},
	Runtime: &sandbox.RuntimeConfig{
		Entrypoint: []string{"sleep", "300"},
	},
	Readiness: &sandbox.ReadinessProbe{
		Check: &sandbox.Command{
			Command: &sandbox.CommandProbe{Argv: []string{"true"}},
		},
	},
	Provisioning: &sandbox.ProvisioningOptions{
		Timeout: sandbox.Duration(2 * time.Minute),
		WaitFor: sandbox.WaitConditionReady,
	},
})
```

  </Tab>

## Result

Metadata from info is a **copy**. Mutating it does not change the sandbox. Reported CPU and memory can differ from what you requested.

<Tabs groupId="language" items={['TypeScript', 'Go']} persist>
  <Tab value="TypeScript">

```ts
const info = sandbox.info();
// info: { id, provider, name?, providerState?, region?, isolation?,
//         resources?, labels, createdAt?, providerMetadata?, state, terminal? }
console.log(info);
```

  </Tab>
  <Tab value="Go">

```go
info := instance.Info()
// info: Id, Provider, Name, ProviderState, Region, Isolation,
//       Resources, Labels, CreatedAt, ProviderMetadata, State, Terminal
fmt.Println(info)
```

  </Tab>
</Tabs>
