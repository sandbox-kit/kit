# Sandbox Kit internal helpers

This module is installed automatically with the sandbox client. A program
imports the public client and one provider:

```sh
go get github.com/sandbox-kit/kit/sdks/go/sandbox@latest
go get github.com/sandbox-kit/kit/sdks/go/providers/daytona@latest
```

Use [github.com/sandbox-kit/kit/sdks/go/sandbox](https://pkg.go.dev/github.com/sandbox-kit/kit/sdks/go/sandbox)
for the client, the sandbox handle, and errors.
